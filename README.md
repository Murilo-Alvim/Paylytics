## Sobre o projeto

Paylytics é uma plataforma SaaS de **monitoramento e análise de transações financeiras em tempo real**, pensada para fintechs que precisam de visibilidade operacional centralizada. O produto consolida informações que normalmente estariam espalhadas entre gateways de pagamento, bancos adquirentes e processadoras — entregando KPIs, gráficos de performance e insights acionáveis em uma única interface.

A inspiração visual vem de produtos como **Stripe**, **Brex** e **Ramp**: design escuro premium, micro-interações sutis e foco em densidade de informação útil, sem poluição visual.

---

## O que o produto oferece

- **Landing page** com hero, lista de features, preview do dashboard e CTAs de conversão
- **Autenticação completa** — cadastro, login, sessão protegida e logout
- **Dashboard principal** com KPIs financeiros, gráfico de volume transacional, share por método de pagamento, distribuição geográfica de receita e ranking diário de aprovação
- **Analytics avançado** com tendências mensais, comparativo entre receita, custo operacional e lucro líquido, e insights gerados automaticamente a partir dos dados
- **Tabela de transações** com busca textual, filtros por status e método, paginação e visualização detalhada de cada cobrança
- **Configurações de conta** com perfil, preferências regionais, controle de aparência, gestão de notificações e ajustes de segurança
- **Design totalmente responsivo** — funciona em desktop, tablet e mobile sem comprometer densidade de informação nem clareza visual

## Stack

Aplicação full-stack moderna construída com:

- **Next.js 14** (App Router) + **React 18** + **TypeScript** em modo estrito
- **Tailwind CSS** com design system próprio
- **Recharts** para visualização de dados
- **Prisma ORM** + **PostgreSQL** (Neon serverless) para persistência
- **bcrypt** + **JWT** em cookie httpOnly para autenticação
- **Vercel** para deploy contínuo a partir do GitHub
